## 1. 本次交付概况

本轮工作以旧版决策支持故事为基础：

> **History（背景支持）→ Routes（核心：比较选择）→ Your plan（核心：形成具体计划）**

主要完成四类工作：历史事件背景、核心信息直读性、主次布局与控件一致性、页面文案与口径统一。没有更换数据、图表类型或模型，也没有新增自动结论文本框。

| 范围 | 结果 |
|---|---|
| 新增历史内容 | 5 个带出处的事件及固定窗口对照 |
| 核心页面 | Routes 默认场景更明确；Your plan 强调历史估计 |
| 布局 | 核心图前移，高级分析折叠，页宽与字号优化 |
| 文案 | 实际应用界面统一为英文；统计层级与时期口径更清楚 |
| 验证 | 浏览器自测从 53 项增加到 59 项，59/59 通过 |

## 2. History：事件作为历史背景

### 新增内容

| 事件 | 用途 |
|---|---|
| 1953 首次确认登顶 | 提供历史起点，不解释现代成功率上升 |
| 1990 年代商业攀登扩张 | 连接支持结构、雇佣人员与氧气使用的长期变化 |
| 2014 雪崩、罢工及南坡取消 | 解释特定季节中断及异常无氧记录 |
| 2015 地震与雪崩 | 解释整季取消，与 2014 分开描述 |
| 2020 疫情许可暂停 | 强调规模中断和 3 条记录的小样本限制 |

### 事件面板行为

- 选择事件后，时间轴自动定位到相关年份。
- 展示事件背景、观察提示和来源链接。
- 使用固定窗口比较事件前、事件中、事件后。
- 显示 expedition 数量、登顶分子/分母、Wilson 区间和雇佣人员比例。
- 提供相关图表跳转与 URL 深链，例如 `?event=closure-2014#history`。
- 明确区分历史背景、描述性对照与因果推断，未将事件写成长期因果结论。

### 新增与修改文件

| 文件 | 说明 |
|---|---|
| `everest-app/data/events.json` | 事件正文、来源与比较窗口的单一信息源 |
| `everest-app/data/events.js` | 由数据脚本同步生成，供浏览器加载 |
| `everest-app/js/history_events.js` | 事件面板、固定窗口汇总与交互 |
| `everest-app/js/module1.js` | 时间轴事件标记及 H1/H2 全年份恢复 |
| `everest-app/js/util.js` | 事件标记、折叠目标自动展开等共享逻辑 |
| `everest-app/pipeline/build_plan_data.py` | 生成事件窗口的 Python 校验值 |
| `everest-app/js/selftest.js` | 新增事件结构及 5 个事件的窗口核验 |

## 3. Routes：默认场景、标题与统计口径

### 默认展示

- 默认改为 **Spring · 2005–2024 · Standard routes**。
- **All history** 保留全部年代、季节和路线入口。
- **Reset** 返回新的默认场景。
- 当前季节、时期和路线组显示在 KPI 与图表提示中。

### 标题与口径

| 调整 | 结果 |
|---|---|
| 当前对比标题 | `Current south–north comparison` |
| 稳定性标题 | `Is the south–north gap stable?` |
| 路线标题 | `Success by route family` |
| 海拔标题 | `Where do expeditions stop?` |
| 图表统计层级 | 对比、差距与路线图明确标注 `Expedition-level` |
| H4 表述 | 改为成员问题，避免与 expedition 级成功率混淆 |
| 页面跳转到 Plan | 侧别、季节、路线继续传入 Your plan |
| 从 Plan 返回 Routes | 时期统一为 2005–2024，与模型部署窗口一致 |

**没有添加自动结论**。相邻图表与 H4–H6 已能承担当前比较与证据解释。

## 4. Your plan：历史估计与刷选提示

- 主标签改为 **Historical estimate for comparable members**，降低被理解为未来登顶预测的风险。
- 保留相似历史成员、模型区间、近期对照、动态解读和样本不足状态。
- 保留 Estimate、Over time、Records、Trust、Connections 等现有功能。
- 标签顺序调整为 **Estimate → Over time → Records → Trust → Connections**。
- 假设卡移到计划结果之后。
- 时间刷选标题改为 **Period for Over time, Connections and Records**，与实际代码行为一致。
- Estimate 的固定模型仍标明 `fitted on 2005–2024`，不随刷选重新训练。

## 5. 主次布局与折叠交互

### History

- 年度时间轴、成功率和支持结构作为主视图。
- 事件改为按需展开。
- 其他历史图和 H1–H3 收入 `Further historical analysis`。

### Routes

- 当前南北比较、差异稳定性和路线成功率前移。
- H4–H6 移到核心比较之后。
- 海拔漏斗、2D/3D、日历与当前季节收入 `Further exploration`。

### 折叠行为

- 使用原生 `<details>` / `<summary>`，不删除任何图表。
- 点击事件和证据链接时，自动展开目标折叠区。
- 展开内容时触发尺寸更新，确保图表与地形正确渲染。
- 已实际验证 H6 深链会展开并定位海拔图。
